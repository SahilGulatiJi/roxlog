    Google Sheet backend

    Point this at a Google Apps Script Web App and every session is written to your own spreadsheet. That gives the version you host on GitHub the same cross-device sync the Claude one has, and your data sits somewhere you own and can open in a browser.

    Stuck? Open the URL in a new tab and see what Google sends back. JSON means the deployment is public and working. A sign-in page or a 404 means "Who has access" is not set to Anyone, or you copied a URL from a deployment that no longer exists.

    These two values are stored in this browser only — they are never written into the page, so the copy in your GitHub repo carries no secrets. You will paste them once on each device you train from.

    How to set the sheet up — five steps
    1. Make a new Google Sheet. Call it anything.
    2. In it: Extensions → Apps Script. Delete whatever is in the editor and paste in the Code.gs file you were sent.
    3. Near the top, change TOKEN to any random string of your own. Save.
    4. Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Authorise it when Google asks — it will warn you the app is unverified, which is expected for your own script. Copy the /exec URL it gives you.
    5. Paste that URL and your token above, then hit Connect & test, then Push all up. Open the sheet and your sessions will be sitting in it.

    "Anyone" is required because your browser calls the script without signing in — the token is what keeps it yours. Treat the URL and token like a password: anyone holding both can read and write your log.

    Apple Watch

    Automatic sync is not possible from a web page. Apple Health data is only reachable through HealthKit, and HealthKit is only available to a native iOS app installed on the phone. There is no web API, on any browser, by design — so neither this page nor anything hosted on your own domain can read your watch directly.

    Three routes actually exist, in increasing order of effort:

    1 · Type it inThree numbers off the workout summary, ten seconds. Already built — open Heart rate & calories under the session form. This is the one that survives contact with a Tuesday morning.
    2 · An iOS ShortcutShortcuts can read your latest workout and copy avg HR, max HR and calories to the clipboard. One tap on the watch or phone, then paste. Free, and about twenty minutes to set up.
    3 · Health Auto Export into the same sheetThe only genuinely automatic route, and once your Google Sheet backend is connected the hard part is already done. The Health Auto Export app posts your workouts as JSON to a REST endpoint on a schedule — that endpoint can be the same Apps Script URL, writing heart rate straight into a second tab. Say the word and I will add the handler. Cost is the app plus an afternoon.

    Worth knowing: your watch is GPS-only, so treadmill distance comes from arm swing and will drift from the belt reading. Trust the treadmill for distance and the watch for heart rate.
